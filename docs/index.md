# Start Here

Welcome. If you've been nodding along to conversations about "AI agents" and
"MCP" while secretly thinking *I have no idea what those are*, this handbook
was written for you — with zero judgment attached.

## The promise of this book

By the end, you'll be able to answer these questions in your own words:

1. **What is an AI agent?** (Short version: a chatbot that can *do* things,
   not just say things.)
2. **What can I safely use one for today?** (Notes, files, reminders — real
   chores, low stakes.)
3. **What is the Model Context Protocol?** (A common plug that lets AI tools
   connect to apps, kind of like USB-C for artificial intelligence.)
4. **How do I set one up on my own computer?** (Step by step, with the exact
   clicks.)

You will not need an API key, a credit card, or a computer science degree for
any of it.

The chapters build on each other, but each one stands on its own too. If

- **"Just tell me the idea."** Read [What is an agent?](01-what-is-an-agent.md)

- **"Is this thing safe?"** Read

- **"Something broke."** Go straight to
  [Troubleshooting](troubleshooting.md). We've all been there.

## The ground rules we wrote by

Three promises, kept on every page:

1. **No condescension.** If a word needs defining, we define it the first
   time. If a step sounds obvious, we say it anyway — because "obvious" is
   only obvious once you know it.
2. **Local first.** Everything here runs on *your* computer. No cloud
   account required, nothing to hand over.
3. **Low stakes first.** We start with uses where even a mistake is boring:
   a messed-up note, a slightly confused reminder. You graduate to bigger
   things only when *you* feel ready.

## What this handbook is not

- It is not a product endorsement. We describe *patterns* that work across
  many desktop clients, with one concrete example client spelled out.
- It is not medical, legal, or financial advice — and agents shouldn't be
  either. If an AI ever tries to give you medical advice, that's a bug in
  your day, not a feature.
- It is not finished. Tech moves; this book is versioned, updated, and
  open source under the MIT license. Corrections welcome.
